# Stamp Duty & Registration Guide (India)

Stamp duty makes a document admissible as evidence in court. An unstamped or under-stamped agreement
can be rejected by courts. Rates are set by each state, so always confirm current rates with the state
registrar or a local lawyer. The below is indicative only.

---

## Key principle

- **Stamping** = paying duty to make the document legally valid as evidence
- **Registration** = recording the document with the sub-registrar (mandatory for some documents)

These are different things. A document can need one, both, or neither.

---

## Rent / Lease agreements

| Duration | Typical requirement |
|---|---|
| Up to 11 months | Stamping required; registration usually optional (why 11-month agreements are common) |
| 12 months to 5 years | Stamping + registration usually mandatory |
| Over 5 years | Stamping + registration mandatory; higher duty |

Stamp duty on rent agreements is typically a small % of annual rent + deposit, varying by state
(e.g. Maharashtra, Karnataka, Delhi all differ). e-Stamping is available in most states via SHCIL.

---

## Common documents and registration need

| Document | Stamping | Registration |
|---|---|---|
| Rent agreement (≤11 months) | Yes | Optional |
| Rent agreement (>11 months) | Yes | Mandatory |
| Sale deed (property) | Yes (high) | Mandatory |
| NDA | Nominal | No |
| Employment agreement | Nominal / often on plain paper | No |
| Founder agreement / SHA | Yes | No (but stamp it) |
| Freelance/consulting | Nominal | No |
| Power of Attorney | Yes | Depends on type |
| Partnership deed | Yes | Recommended (register with RoF) |
| MoU | Nominal | No |

---

## Practical guidance for the user

1. For low-stakes documents (NDA, freelance contract), a nominal stamp paper (Rs 100-500) is usually
   enough to make it valid.
2. For anything involving property or large sums, use correct ad-valorem stamp duty and register.
3. e-Stamping (SHCIL / state portals) is the easiest route in most states.
4. When in doubt about the exact rate, tell the user to check their state's stamp act or ask a local
   documentation lawyer - rates change and vary too much to hardcode.

Always end a drafted agreement with a note like:
> "Note: This agreement should be printed on stamp paper of the value applicable in [State] and
> [registered / stamped] as per local requirements before signing. Confirm current rates with your
> state sub-registrar or a local advocate."
